# 🎮 Jeu Simon - Projet C# MAUI

Ce projet est un jeu Simon développé avec .NET MAUI en C#. Il est destiné aux enfants de 5 à 8 ans et fonctionne avec une interface graphique colorée, des sons, et une logique de séquences à reproduire.

## Fonctionnalités

- Séquences de couleurs et sons à mémoriser
- Difficulté qui augmente à chaque tour
- Système de score
- Sons différents pour chaque bouton
- Interface simple et adaptée aux enfants

## Structure du projet

- `Models/` : les classes de données (ex : SimonGame.cs)
- `ViewModels/` : la logique du jeu
- `Views/` : les interfaces graphiques en XAML
- `Platforms/` : les fichiers spécifiques à chaque plateforme
